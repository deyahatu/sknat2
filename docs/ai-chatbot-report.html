المؤلف: Mahdy Hamdan + Claude

1. الملخص التنفيذي

تم تطوير ودمج مساعد ذكي (Chatbot) داخل منصة سكنات لمساعدة الطلاب والملاك والزوار على أسئلة المنصة: البحث عن العقارات، خطوات الحجز، السياسات، وبيانات المستخدم الشخصية. المساعد مقيد بسياق سكنات فقط ويرفض أي سؤال خارج النطاق. يدعم لهجة فلسطينية والإنجليزية، ويتكامل مع قاعدة البيانات عبر استدعاءات أدوات (Tool Calling) محددة الصلاحيات حسب دور المستخدم.

الحالة

تم النشر على بيئة التطوير. يعمل من نهاية لنهاية مع DeepSeek-Chat. جاهز للاختبار من المستخدمين النهائيين.

المؤشرات

متوسط زمن الاستجابة: 6–10 ث.
متوسط Tokens/رد: ~800 in / ~150 out.
التكلفة المتوقعة: أقل من $0.0005 لكل رد.

2. النطاق والمميزات

المغطّى

  • إجابات على كيفية الاستخدام (How-to): الحجز، الدفع، السحب، تسجيل عقار.
  • الوصول لبيانات المستخدم: حجوزاتي، عقاراتي، رصيد المحفظة، إشعاراتي.
  • بحث طبيعي عن العقارات: مثل "بدي شقة لذكور قريبة من الحرم القديم تحت 600 شيكل".
  • أسئلة شائعة (FAQ): سياسات الاسترداد، الرسوم، الدعم، عن المنصة.
  • رفض مهذب لأي سؤال خارج النطاق.

خارج النطاق (v1)

  • الردود التدفقية (Streaming) — مرحلة v2.
  • أدوات إدارية (Admin tools) — يستخدم الأدمن لوحة التحكم مباشرة.
  • البحث الدلالي عبر Embeddings (RAG) — حالياً FAQ ثابت.

3. البنية المعمارية

React ChatWidget (floating button + popup)
   │  POST /api/chat/message
   ▼
Express Route /api/chat/message
   │
   ├─ Rate limit (30/5min authed, 10/5min guest)
   ├─ Optional auth (JWT cookie → user.role)
   ├─ Prompt-injection heuristic
   ├─ Resolve/create ChatSession (DB for authed, ephemeral for guest)
   ├─ Trim history by token budget (~12k chars)
   ├─ Filter tools by role (public / authed / owner)
   ├─ Call DeepSeek (OpenAI-compatible)
   │     system: scope + role hint + Palestinian dialect
   │     tools: 5 functions in OpenAI format
   ├─ Tool-use loop (max 5 hops):
   │     execute tool with { userId, userRole }
   │     append tool_result → re-call
   ├─ Persist messages + token usage (authed)
   └─ Return { sessionId, text, toolCalls, usage }

6. اختبار Playwright — النتائج

نجح

  • فتح/إغلاق الويدجت من زر FAB.
  • إرسال رسائل عربي/إنجليزي والحصول على رد ضمن 6–10 ثوانٍ.
  • استدعاء search_properties وعرض النتائج كبطاقات قابلة للنقر.
  • الانتقال من البطاقة إلى صفحة العقار (/property/:id).
  • رفض الأسئلة خارج النطاق (نكتة، 2+2، كود برمجي).
  • التجاوب مع موبايل 390×844.
  • اختفاء زر FAB على الموبايل عند فتح اللوحة.

تم إصلاحه

  • روابط 404: كانت /properties/:id ≠ المسار /property/:id.
  • Markdown خام: الويدجت يزيل **bold** و[text](url) قبل العرض.
  • صورة بديلة: أيقونة بيت ملوّنة بدل صورة مكسورة.
  • تداخل FAB + close: إخفاء FAB على الموبايل.
  • قيمة العملة: ₪ بدلاً من ر.س.
  • التضييق الجغرافي: ربط النطاق بنابلس + جامعة النجاح.
  • اللهجة: فلسطينية (بدك، هلأ، شو) بدل خليجية.
  • تسرب نصوص أجنبية: منع غير العربي/الإنجليزي.

9. الأمان والخصوصية

الموضوعالوضع الحاليالتوصية
تخزين المفاتيح DEEPSEEK_API_KEY في server/.env (gitignored) دوّر المفتاحين الـAnthropic+DeepSeek اللي ظهروا في الشات. استخدم secret manager للإنتاج.
Authorization على الأدوات كل executor يتحقق من userId/userRole قبل التنفيذ + فلتر filterToolsByAccess قبل تمرير الأدوات لـ LLM دفاع بطبقتين كافي. اختبار: محاولة وصول طالب لـ get_my_properties = الأداة محذوفة من الـ context.
Prompt Injection Regex heuristic لرسائل من نوع "ignore previous instructions" يكفي للمستخدم العادي. الـ blast radius محدود بسبب الأدوات الخمس.
Rate Limiting 30/5min مسجّل، 10/5min زائر راقب 429s في الـ logs. عدّل لو موزّع الزوار عبر IPs.
PII في الـ prompt اسم + ID المستخدم في system prompt DeepSeek/OpenAI ما تتدرب على API calls، لكن سجلات الأخطاء قد تحوي PII.
تنبيه أمني: مفتاحان sk-ant-... وsk-435e... ظهرا في شات المحادثة. يجب تدويرهما من لوحات Anthropic و DeepSeek قبل النشر للإنتاج.

10. التكلفة المتوقعة

استناداً إلى DeepSeek-Chat بسعر $0.27/1M input + $1.10/1M output:

  • رد واحد متوسط: ~800 in + 150 out ≈ $0.00038.
  • 1000 رد شهرياً: ~$0.38.
  • 10,000 رد شهرياً: ~$3.80.
مقارنة: نفس الحمل على Claude Haiku 4.5 ≈ $8.80، وعلى GPT-4o-mini ≈ $1.30. DeepSeek هو الأرخص حالياً.
