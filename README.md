# 🏠 سكنات — منصة السكن الطلابي

منصة تربط الطلاب الباحثين عن سكن بأصحاب العقارات الذين يوفرون سكناً طلابياً.

## التقنيات

- **Frontend:** React 19 + Vite
- **Routing:** React Router
- **Styling:** CSS (RTL Arabic)
- **Icons:** React Icons

## التشغيل

```bash
npm install
npm run dev
```

## الصفحات

| الصفحة | الرابط | الوصف |
|--------|--------|-------|
| الرئيسية | `/` | صفحة الهبوط مع العقارات المميزة |
| تسجيل الدخول | `/login` | نموذج تسجيل الدخول |
| إنشاء حساب | `/register` | نموذج التسجيل (طالب / مالك عقار) |
| البحث عن سكن | `/search` | بحث وفلترة العقارات |
| تفاصيل العقار | `/property/:id` | معرض صور ومواصفات العقار |

## الفريق

- **مهدي** — واجهة المستخدم، إدارة العقارات، نظام البحث
- **ضياء** — المصادقة، إدارة المستخدمين، لوحة الإدارة
- **عبدالله** — نظام الحجز، نظام التقييمات
