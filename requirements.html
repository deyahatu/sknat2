منصة سكنات - مستند المتطلبات

Software Requirements Specification (SRS)

1. وصف المشروع

اسم المشروع: سكنات (Sakanat)

الفكرة: منصة إلكترونية تساعد طلاب الجامعات الفلسطينية في البحث عن سكن مناسب بالقرب من جامعاتهم. تربط بين الطلاب الباحثين عن سكن وأصحاب العقارات، وتعمل بنظام الضمان المالي حيث يدفع الطالب للمنصة والمنصة تحول المبلغ للمالك بناءً على طلب سحب.

التقنيات: React + Vite (واجهة أمامية) | Node.js + Express (خادم خلفي) | PostgreSQL + Prisma (قاعدة بيانات)

2. أنواع المستخدمين (Actors)

سوبر أدمن (Admin)

يدير كامل المنصة - المستخدمين والعقارات والحجوزات وطلبات السحب

مالك عقار (Owner)

يضيف عقاراته على المنصة، يدير الحجوزات الواردة، يطلب سحب أرباحه

طالب (Student)

يبحث عن سكن، يحجز، يدفع، يكتب تقييمات

3. المتطلبات الوظيفية (Functional Requirements)

FR1 - إدارة الحسابات

الرقمالمتطلب
FR1.1تسجيل حساب جديد (طالب أو مالك عقار)
FR1.2تسجيل دخول بالبريد الإلكتروني وكلمة السر
FR1.3تسجيل خروج
FR1.4استعادة كلمة السر عبر البريد الإلكتروني
FR1.5تعديل الملف الشخصي (الاسم، الهاتف، الصورة الشخصية)
FR1.6تغيير كلمة السر

FR2 - إدارة العقارات

الرقمالمتطلب
FR2.1المالك يضيف عقار جديد (العنوان، الوصف، السعر، الصور، عدد الغرف، المساحة)
FR2.2المالك يعدل بيانات عقاراته
FR2.3المالك يحذف عقاراته
FR2.4عرض قائمة العقارات المتاحة
FR2.5عرض تفاصيل عقار معين
FR2.6البحث والفلترة (بالموقع، السعر، عدد الغرف)

FR3 - نظام الحجز

الرقمالمتطلب
FR3.1الطالب يطلب حجز عقار (تاريخ البداية والنهاية)
FR3.2المالك يقبل أو يرفض طلب الحجز
FR3.3الطالب يلغي الحجز
FR3.4عرض حجوزات الطالب
FR3.5عرض الحجوزات الواردة للمالك

FR4 - التقييمات

الرقمالمتطلب
FR4.1الطالب يكتب تقييم ويعطي نجوم (1-5) للعقار
FR4.2عرض تقييمات عقار معين
FR4.3حذف التقييم (بواسطة صاحبه أو الأدمن)
FR4.4الطالب يقيّم نفس العقار مرة واحدة فقط

FR5 - نظام الدفع والضمان

الرقمالمتطلب
FR5.1الطالب يدفع مبلغ الحجز للمنصة (نظام ضمان)
FR5.2المنصة تحتفظ بالمبلغ كضمان لحين قبول الحجز
FR5.3المبلغ يُضاف لمحفظة المالك بعد قبول الحجز
FR5.4استرجاع المبلغ للطالب عند إلغاء الحجز

FR6 - المحفظة وطلبات السحب

الرقمالمتطلب
FR6.1كل مالك عقار لديه محفظة إلكترونية برصيد
FR6.2المالك يقدم طلب سحب للمبلغ المتوفر في محفظته
FR6.3الأدمن يوافق أو يرفض طلب السحب
FR6.4عرض سجل طلبات السحب للمالك

FR7 - لوحة تحكم السوبر أدمن

الرقمالمتطلب
FR7.1عرض جميع المستخدمين وإدارتهم
FR7.2حذف مستخدمين مخالفين
FR7.3عرض جميع العقارات
FR7.4حذف عقارات مخالفة
FR7.5إدارة طلبات السحب (قبول / رفض)
FR7.6عرض إحصائيات المنصة (عدد المستخدمين، العقارات، الحجوزات)
