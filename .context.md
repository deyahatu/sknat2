## What is Sakanat?

Palestinian student housing platform (Arabic RTL, Cairo font). Team project:
- **Mahdy (me)**: Auth, user management, admin dashboard
- **Abdullah**: Booking + reviews (separate scope)

## Tech Stack

- **Frontend**: React + Vite (port 5173)
- **Backend**: Node/Express 5 + Prisma 7 + PostgreSQL 16 (port 5001)
- **Auth**: JWT in httpOnly cookies + Bearer header fallback
- **DB**: PostgreSQL `sakanat` on localhost:5432, user `mahdy` (no password)
- **Repo**: https://github.com/MahdyHamdan2001/sknat.git

## Important Notes

- **Port 5001** (not 5000 — macOS AirPlay blocks 5000)
- **Prisma 7** uses adapter pattern (`@prisma/adapter-pg`), no `url` in schema.prisma
- **Password reset**: No email service — reset links logged to server console only
- **Vite proxy**: `/api` requests → `localhost:5001`
- **Git**: NO AI attribution in commits ever. Author: `Mahdy Hamdan <mahdyadel21@gmail.com>`

## How to Run

```bash
# Terminal 1 - Backend
cd server
npm run dev          # runs on port 5001

# Terminal 2 - Frontend  
npm run dev          # runs on port 5173 (Vite)

# PostgreSQL must be running
brew services start postgresql@16
```

## Project Structure

```
server/
├── .env                         # DB_URL, JWT_SECRET, PORT=5001, CLIENT_URL
├── prisma/schema.prisma         # User model (resetToken/resetTokenExpiry fields)
├── src/
│   ├── index.js                 # Express entry
│   ├── seed.js                  # DB seeder
│   ├── utils/prisma.js          # PrismaClient with PrismaPg adapter
│   ├── utils/jwt.js             # generateToken / verifyToken
│   ├── utils/crypto.js          # generateResetToken / hashToken
│   ├── middleware/auth.js       # authenticate + authorize
│   └── routes/
│       ├── auth.js              # register, login, logout, me, forgot/reset-password, change-password
│       └── users.js             # profile CRUD, admin user list/delete

src/
├── App.jsx                      # AuthProvider, GuestRoute, ProtectedRoute, all routes
├── context/AuthContext.jsx       # Auth state + refreshUser
├── utils/api.js                 # Fetch wrapper for all API calls
├── pages/
│   ├── LoginPage.jsx            # Real auth
│   ├── RegisterPage.jsx         # Real auth
│   ├── ForgotPasswordPage.jsx   # Sends reset request
│   ├── ResetPasswordPage.jsx    # Token-based reset form
│   ├── ProfilePage.jsx          # View/edit profile + change password
```
